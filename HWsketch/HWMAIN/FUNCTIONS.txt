HWMAIN 함수 설명서

이 문서는 HWsketch/HWMAIN 폴더의 Arduino 메인 코드 구조와 각 함수 역할을 정리한 파일입니다.
현재 코드는 부품별로 파일이 분리되어 있습니다.


1. HWMAIN.ino

setup()
- Arduino 보드가 켜지거나 리셋될 때 한 번 실행됩니다.
- 실제 초기화 작업은 setupDevice()로 넘깁니다.

loop()
- setup() 이후 계속 반복 실행됩니다.
- 실제 반복 동작은 loopDevice()로 넘깁니다.


2. device.cpp / device.h

역할
- 장치 전체 흐름을 제어합니다.
- 버튼 입력에 따라 시작, 리셋, 알코올 재측정, 결과 화면 전환을 실행합니다.
- 심박/알코올/알림의 세부 알고리즘은 각 부품 파일로 분리되어 있습니다.

setupDevice()
- 버튼, PPG 심박 센서, ZE-29A 알코올 센서, OLED, 알림 출력, BLE 통신을 초기화합니다.
- 시작 화면으로 "Drunksafe"를 표시합니다.

loopDevice()
- Arduino loop()에서 계속 호출되는 메인 상태 처리 함수입니다.
- 시작 전에는 BTN_START_RESET 버튼을 기다립니다.
- 시작 후에는 심박 갱신, 리셋 버튼, 알코올 측정 버튼, 화면 전환 버튼을 처리합니다.

runBackgroundTasks()
- 알코올 측정 중에도 계속 실행되어야 하는 작업 묶음입니다.
- PPG 심박 샘플링, ZE-29A 상태 갱신, 부저/진동 패턴 진행, raw PPG 앱 전송을 처리합니다.

updateBpmAndSend()
- runBackgroundTasks()를 실행한 뒤, 일정 주기마다 최신 심박 특징값을 BLE 전송 형식으로 넘깁니다.
- 현재 화면이 BPM 화면이면 OLED BPM 숫자도 갱신합니다.

runAlcoholMeasurement()
- ZE-29A 알코올 측정을 시작하고 완료될 때까지 상태를 확인합니다.
- 내부 반복 중 updateBpmAndSend()를 계속 호출하므로 알코올 측정 중에도 심박 알고리즘이 멈추지 않습니다.
- OLED에는 ZE-29A 상태 안내 문구를 표시합니다.

showAlcoholSensorStatus()
- ZE-29A 상태값을 OLED 안내 문구로 바꿉니다.
- 예: Warming, Blow, Keep Blowing, Complete, Timeout 등.

showNextMeasurementScreen()
- 결과 화면을 순서대로 전환합니다.
- 순서: 판별 상태 -> 알코올 수치 -> BPM -> 판별 상태.

startDevice()
- 시작 버튼을 눌렀을 때 최초 측정 흐름을 시작합니다.
- 초기 심박값을 읽고, 첫 알코올 측정을 실행한 뒤 결과 화면을 표시합니다.

resetDevice()
- 장치를 홈 상태로 초기화합니다.
- 측정값, 화면 순서, 현재 BPM, 판별 상태를 초기값으로 되돌립니다.


3. ppg_sensor.cpp / ppg_sensor.h

역할
- 펄스센서의 PPG ADC 값을 읽고 BPM을 계산합니다.
- raw PPG 데이터와 계산된 심박 특징값을 BLE 전송용으로 제공합니다.

initBpmSensor()
- ESP32 ADC 해상도를 12비트로 설정합니다.

updateBpmSensor()
- delay 없이 millis() 기준으로 10ms마다 PPG 값을 읽습니다.
- raw 값은 앱 그래프용 버퍼에 저장합니다.
- 보정값은 5초 길이의 원형 버퍼에 저장합니다.
- 시작 후 10초 안정화 시간을 둔 뒤, 5초 단위로 BPM을 계산합니다.

measurePpg()
- GPIO36에서 ADC 값을 4번 읽고 평균값을 반환합니다.
- 순간 잡음을 줄이기 위한 내부 함수입니다.

correctPpg(int rawValue)
- raw PPG 값에 저역 통과 필터와 고역 통과 필터를 적용합니다.
- 박동 피크 검출에 더 적합한 보정 파형을 만듭니다.

saveCorrectedPpg(float correctedValue, unsigned long sampleTime)
- 보정된 PPG 값과 측정 시간을 5초 원형 버퍼에 저장합니다.

findPpgPeaks(int peakIndexes[], int &peakCount)
- 보정된 PPG 파형에서 심박 피크 후보를 찾습니다.
- 너무 가까운 피크가 겹치면 더 큰 피크만 남겨 중복 검출을 줄입니다.

calculateBpmFromPeaks(int peakIndexes[], int peakCount)
- 피크 사이 시간 간격(IBI)을 이용해 BPM을 계산합니다.
- IBI 표준편차가 너무 크면 움직임/접촉 불안정으로 보고 표시 BPM 갱신을 보류합니다.

push_trend(...)
- 20초, 1분, 5분 이동평균과 변화량을 계산하는 공통 내부 함수입니다.

updateBpmCalculation()
- 5초 버퍼가 준비되면 피크 검출과 BPM 계산을 실행합니다.

Bpm()
- OLED 표시용 최신 안정 BPM을 반환합니다.
- 아직 안정 BPM이 없으면 0을 반환합니다.

getLatestPpgFeatures()
- BLE/app 전송용 최신 심박 특징값 묶음을 반환합니다.

getRawDataAvailable()
- 앱 그래프 전송용 raw PPG 샘플이 몇 개 쌓였는지 반환합니다.

popRawDataBatch(...)
- raw PPG 샘플을 일정 개수 꺼내 BLE 전송 함수로 넘길 수 있게 합니다.


4. alcohol_sensor.cpp / alcohol_sensor.h

역할
- ZE-29A 알코올 센서와 Serial2로 통신합니다.
- 측정 시작, 상태 조회, 결과 패킷 처리, timeout 처리를 담당합니다.

initAlcoholSensor()
- Serial2를 9600bps로 시작합니다.
- ZE-29A를 idle 상태로 둡니다.

startAlcoholMeasurement()
- 이전 UART 수신 버퍼를 비웁니다.
- 측정 상태값과 결과값을 초기화합니다.
- ZE-29A 측정 시작 명령을 보냅니다.

updateAlcoholSensor()
- 측정 중 500ms마다 ZE-29A 상태 조회 명령을 보냅니다.
- Serial2에 들어온 완전한 9바이트 패킷을 읽어 처리합니다.
- 45초가 지나면 timeout으로 종료합니다.
- delay 없이 동작하므로 심박 측정 흐름을 막지 않습니다.

readZe29aPacket(byte* packet)
- Serial2에 이미 들어온 데이터 중 유효한 9바이트 패킷을 읽습니다.
- checksum이 맞는 패킷만 true로 반환합니다.

handleZe29aPacket(byte* packet)
- 0x85 상태 패킷이면 현재 진행 상태를 갱신합니다.
- 0x86 결과 패킷이면 알코올 결과값을 저장하고 측정을 완료합니다.

setZe29aStatusFromState(byte state)
- ZE-29A 상태 바이트를 AlcoholSensorStatus enum으로 변환합니다.
- 0x37 상태에서는 결과 요청 명령을 보냅니다.

isAlcoholMeasurementFinished()
- 알코올 측정이 끝났는지 반환합니다.

getAlcoholSensorStatus()
- OLED 안내 문구 선택에 사용할 현재 ZE-29A 상태를 반환합니다.

alcohol()
- 가장 최근 알코올 측정 결과를 반환합니다.


5. alert.cpp / alert.h

역할
- 부저와 진동모터 알림 패턴을 담당합니다.
- millis() 기반으로 동작하므로 심박/알코올 측정을 막지 않습니다.

initAlert()
- 부저 GPIO25와 진동모터 GPIO26을 출력으로 설정합니다.
- 초기 상태를 OFF로 둡니다.

updateAlertPattern()
- 현재 알림 패턴을 시간에 맞춰 다음 단계로 진행합니다.
- delay()를 쓰지 않아 다른 센서 갱신과 동시에 동작할 수 있습니다.

- 알림이 진행 중이 아닐 때 짧은 두 번의 알림 패턴을 시작합니다.

beep(int type)
- 부저 출력 상태를 제어하는 내부 함수입니다.
- 현재 회로 기준으로 type 2가 ON, type 1이 OFF입니다.

vibe(int type)
- 진동모터 출력 상태를 제어하는 내부 함수입니다.


6. buttons.cpp / buttons.h

initButtons()
- 시작/리셋, 다음 화면, 알코올 측정 버튼을 INPUT_PULLUP 입력으로 설정합니다.

isButtonPressed(int pin)
- 버튼 눌림을 debounce 처리해서 true/false로 반환합니다.
- 버튼을 놓을 때까지 기다리는 동안 runBackgroundTasks()를 호출해 센서 흐름이 완전히 멈추지 않게 합니다.


7. display.cpp / display.h

initDisplay()
- OLED I2C, 주소, UTF-8 출력 모드를 초기화합니다.

showEnglishText(const char* text)
- 영문 단일 문구를 OLED 중앙에 표시합니다.

showKorean2Lines(const char* line1, const char* line2)
- UTF-8 문자열 두 줄을 OLED 중앙에 표시합니다.

showStateScreen(SafetyState safetyState)
- 최종 판별 상태를 OLED에 표시합니다.

showAlcoholValueScreen(float maxAlcoholValue)
- 알코올 측정 결과를 OLED에 표시합니다.

showHeartRateScreen(int currentBpm)
- BPM 값을 OLED에 표시합니다.

- 알코올 측정 중 현재값/최대값 표시용 함수입니다.
- 현재 흐름에서는 ZE-29A 상태 안내 화면을 주로 사용합니다.

showResetMessageScreen()
- 초기화 안내 화면을 표시합니다.


8. comms.cpp / comms.h

initComms()
- BLE 장치 이름, service, characteristic, advertising을 초기화합니다.
- 장치 이름은 ESP32 Bluetooth MAC 뒤 2바이트를 붙여 구분합니다.

sendDataToApp(const PpgFeatures& features, float alcoholVal)
- 심박 특징값과 알코올 값을 JSON 형태로 만듭니다.
- 현재 실제 BLE notify 줄은 주석 처리되어 있습니다.

sendRawDataToApp(unsigned long start_t, const int* values, int count)
- raw PPG 그래프용 ADC 샘플 묶음을 JSON 형태로 만듭니다.
- 현재 실제 BLE notify 줄은 주석 처리되어 있습니다.


9. sensors.cpp / sensors.h

역할
- 현재는 부품별 센서 헤더를 한 번에 include하는 공용 진입점 역할을 합니다.
- 최종 안전 상태 판별 함수 judgeSafetyState()도 여기에 남아 있습니다.

judgeSafetyState(float maxAlcoholValue, int currentBpm)
- 알코올 수치와 BPM을 기준으로 최종 안전 상태를 판단할 위치입니다.
- 현재 구현은 기존과 동일하게 임시 랜덤 판별입니다.


전체 실행 흐름

1. setup() -> setupDevice()
2. setupDevice()가 버튼, PPG, ZE-29A, OLED, 알림, BLE를 초기화
3. loop() -> loopDevice()
4. 시작 전: BTN_START_RESET을 기다림
5. 시작 후: runAlcoholMeasurement()로 첫 알코올 측정
6. 알코올 측정 중에도 updateBpmAndSend()가 반복 호출되어 PPG/BPM 측정 유지
7. 측정 완료 후 BTN_NEXT로 판별 상태, 알코올 수치, BPM 화면 전환
8. BTN_BREATH를 누르면 ZE-29A 알코올 측정을 다시 실행
9. BTN_START_RESET을 다시 누르면 홈 상태로 초기화
