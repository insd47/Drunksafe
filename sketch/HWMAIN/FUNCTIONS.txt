HWMAIN 함수 설명

이 파일은 sketch/HWMAIN 폴더에 있는 Arduino 코드의 주요 함수 역할을 정리한 문서입니다.


1. HWMAIN.ino

setup()
- Arduino 보드가 켜지거나 리셋될 때 한 번 실행되는 시작 함수입니다.
- 실제 초기화 작업은 setupDevice()에 맡깁니다.

loop()
- setup() 이후 계속 반복 실행되는 Arduino 기본 함수입니다.
- 버튼 입력, 측정, 화면 전환 같은 반복 동작은 loopDevice()에서 처리합니다.


2. buttons.cpp

initButtons()
- 시작/리셋 버튼, 다음 화면 버튼, 음주 측정 버튼 핀을 입력 모드로 설정합니다.
- INPUT_PULLUP을 사용하므로 버튼을 누르면 LOW로 읽히는 구조입니다.

isButtonPressed(int pin)
- 지정한 버튼 핀이 눌렸는지 확인합니다.
- 짧은 딜레이로 버튼 튐을 줄이고, 버튼에서 손을 뗄 때까지 기다린 뒤 true를 반환합니다.


3. comms.cpp

sendHeartRateToServer(int bpm)
- 심박수 값을 서버나 다른 장치로 보내기 위해 남겨둔 함수입니다.
- 현재 코드에서는 실제 통신을 하지 않고, 나중에 Wi-Fi/HTTP/Bluetooth 같은 전송 코드를 넣을 자리입니다.


4. device.cpp

updateBpmAndSend()
- 장치가 시작된 상태에서 일정 시간이 지나면 새 심박수를 만듭니다.
- 새 심박수는 sendHeartRateToServer()로 전달하고, 현재 화면이 심박수 화면이면 화면도 갱신합니다.

showNextMeasurementScreen()
- 다음 버튼을 눌렀을 때 보여줄 화면을 순서대로 바꿉니다.
- 현재 판별 상태 화면, 알코올 측정값 화면, 심박수 화면을 번갈아 표시합니다.

runAlcoholMeasurement()
- 음주 측정 버튼을 눌렀을 때 알코올 측정을 진행합니다.
- 정해진 측정 시간 동안 여러 번 alcohol() 값을 읽고, 그중 가장 높은 값을 저장합니다.
- 측정 중에는 현재값과 최대값을 OLED 화면에 계속 보여줍니다.

resetDevice()
- 시작/리셋 버튼을 길게 누르거나 리셋 조건이 들어왔을 때 장치 상태를 초기화합니다.
- 측정값, 심박수, 화면 순서, 시작 여부를 초기 상태로 되돌리고 첫 화면을 표시합니다.

startDevice()
- 장치를 처음 시작할 때 실행됩니다.
- 초기 심박수를 만들고 전송한 뒤, 첫 알코올 측정을 실행하고 첫 결과 화면을 표시합니다.

setupDevice()
- 장치 전체의 초기 설정을 담당합니다.
- 랜덤 값 초기화, 버튼 초기화, OLED 초기화를 수행하고 첫 안내 화면을 표시합니다.

loopDevice()
- 장치의 메인 반복 처리 함수입니다.
- 시작/리셋 버튼, 음주 측정 버튼, 다음 화면 버튼 입력을 확인하고 각각의 동작을 실행합니다.
- 장치가 시작된 뒤에는 주기적으로 심박수 업데이트도 처리합니다.


5. display.cpp

drawCenteredUTF8(const char* text, int y)
- 화면 내부에서만 쓰는 보조 함수입니다.
- UTF-8 문자열의 폭을 계산해서 OLED 가로 중앙에 출력합니다.

initDisplay()
- OLED 화면을 사용할 수 있도록 I2C와 OLED 설정을 초기화합니다.
- 한글 출력을 위해 UTF-8 출력 모드도 켭니다.

showEnglishText(const char* text)
- 영어 문장을 OLED 중앙에 한 줄로 표시합니다.

showKorean2Lines(const char* line1, const char* line2)
- 한글 문장 두 줄을 OLED 화면 중앙 영역에 표시합니다.

showStateScreen(SafetyState safetyState)
- 현재 판별 결과를 화면에 표시합니다.
- SAFE, CAUTION, DANGER 상태에 따라 서로 다른 안내 문구를 보여줍니다.

showAlcoholValueScreen(float maxAlcoholValue)
- 저장된 최대 알코올 측정값을 퍼센트 형식으로 화면에 표시합니다.

showHeartRateScreen(int currentBpm)
- 현재 심박수를 BPM 형식으로 화면에 표시합니다.

showBreathMeasuringScreen(float currentValue, float maxValue)
- 알코올 측정 중 현재 측정값과 최대 측정값을 화면에 표시합니다.

showResetMessageScreen()
- 장치가 초기화될 때 초기화 안내 화면을 표시합니다.


6. sensors.cpp

Bpm()
- 현재는 테스트용 랜덤 심박수 값을 반환합니다.
- 실제 심박 센서를 연결하면 이 함수 안에 센서 읽기 코드를 넣으면 됩니다.

alcohol()
- 현재는 테스트용 랜덤 알코올 측정값을 반환합니다.
- 실제 알코올 센서를 연결하면 이 함수 안에 센서 읽기 및 변환 코드를 넣으면 됩니다.

judgeSafetyState(float maxAlcoholValue, int currentBpm)
- 알코올 측정값과 심박수를 바탕으로 SAFE, CAUTION, DANGER 중 하나를 판단하는 함수입니다.
- 현재는 테스트용 랜덤 판별을 사용하고 있으며, 실제 판별 기준이 정해지면 이 함수의 조건식을 수정하면 됩니다.


전체 실행 흐름

1. setup()이 setupDevice()를 호출해서 버튼과 OLED를 초기화합니다.
2. loop()가 loopDevice()를 계속 반복 호출합니다.
3. 시작 버튼을 누르면 startDevice()가 실행되어 초기 심박수와 알코올 측정을 진행합니다.
4. 음주 측정 버튼을 누르면 runAlcoholMeasurement()가 다시 실행됩니다.
5. 다음 버튼을 누르면 showNextMeasurementScreen()이 결과 화면을 순서대로 바꿉니다.
6. 장치가 시작된 상태에서는 updateBpmAndSend()가 주기적으로 심박수를 갱신합니다.
